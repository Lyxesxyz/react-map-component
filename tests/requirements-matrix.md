# Requirement traceability matrix

Statuses describe repository evidence, not approval of external data, infrastructure, or publication policy.

The React and Angular folders share the engine files (`packages/geospatial-map-core`), so the engine's unit tests are evidence for both. "Primary evidence" is the shared engine, the React folder and the browser suite. "Angular evidence" is the Angular folder's unit tests (`packages/geospatial-map-angular/test`) and the Angular browser projects (`chromium-angular`, `firefox-angular`, `webkit-angular`, `chromium-angular-zone`), which run the same specs against the Angular demo; the `parity` project compares the two demos' DOM.
